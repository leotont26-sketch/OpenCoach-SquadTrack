# OpenCoach · SquadTrack 📋

Modernes Anwesenheits- und Teammanagement für Jugend- und Amateurfußball.  
Einfach. Transparent. Ohne Datenbank. Ohne Werbung. Ohne Abo.  

---

## 📌 Was ist SquadTrack?

**SquadTrack** ist ein webbasiertes Anwesenheits- und Organisationstool für Fußballvereine, Trainer und Mannschaften.

Es hilft dabei:
- Anwesenheiten einfach zu verwalten
- Trainings- und Spieltage zu organisieren
- Spielerstatistiken transparent darzustellen
- Fehlzeiten schnell zu erkennen
- Fairness im Team besser einzuschätzen
- den Überblick über die gesamte Mannschaft zu behalten

Das Ganze läuft auf einem einfachen Webspace mit PHP.  
Keine Datenbank. Keine Registrierung. Keine Cloud-Pflicht.

## 📦 Installation

1. ZIP herunterladen und entpacken
2. install.php auf Webspace hochladen
3. im Browser aufrufen
4. Installation auswählen
5. Fertig

### Empfohlen
- Direkt nach Installation das Admin-Passwort ändern
